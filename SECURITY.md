# Security policy

If you find a vulnerability in Stingward itself (for example a way for an audited project or skill to run code, hide findings or leak data through the report), please report it privately: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

Please include the Stingward version (`stingward --version`), the command you ran and a minimal sample that reproduces it. We aim to reply within 7 days.

Findings that Stingward reports about *your* project are not vulnerabilities in Stingward. False positives and misses are welcome as regular issues.
